# Traktor Playlist Generator

**ACHTUNG!**  
- Erst starten, nachdem alle neuen Tracks in Traktor importiert wurden per "Import to Collection"!


Auf USCHI / Hauptrechner:
1. Per Total Commander oder so die Tracks auf Dateiebene in die entspechenden Ordner einpflegen 
2. Traktor starten
3. In Traktor: Import to Collection
4. Traktor schließen   ← wichtig! (collection.nml wird geschrieben)
5. C#-Tool Traktor Playlist Generator ausführen
6. Syncthing laufen lassen
